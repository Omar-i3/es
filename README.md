# 🌟 نماء | المستشار الاستثماري الذكي المتوافق مع الشريعة الإسلامية
### Namaa — Autonomous AI Islamic Robo-Advisor Platform

منصة استثمار وإدارة ثروات ذكية تعمل بالذكاء الاصطناعي المستقل (AI Autopilot) وفق ضوابط الشريعة الإسلامية ومعايير هيئة المحاسبة والمراجعة للمؤسسات المالية الإسلامية (**AAOIFI Standards**).

---

## 🚀 المميزات الرئيسية (Key Features)

### 1. 🌐 واجهة عربية أصيلة وتجربة مستخدم عصرية (Arabic-First & RTL)
- تصميم مالي إسلامي فاخر: **Dark Slate & Emerald Glow with Gold Accents**.
- دعم كامل لاتجاه النصوص من اليمين لليسار (`dir="rtl"`).
- تبديل فوري بين العملات: **الريال السعودي (ر.س)** و **الدولار الأمريكي ($)**.
- متجاوب بالكامل مع أجهزة الجوال والشاشات المكتبية.

### 2. 🌙 منظومة الامتثال الشرعي (Sharia-Compliance Engine)
- **فلترة مالية صارمة (AAOIFI Standard 21)**:
  - نسبة الديون الربوية < 33% من القيمة السوقية.
  - النقدية والاستثمارات ذات الفائدة < 33%.
  - الإيرادات العرضية غير النقية < 5%.
  - خلو تام من أنشطة الخمور، القمار، التبغ، السلاح، والبنوك التقليدية.
- **أصول إسلامية معتمدة**:
  - أسهم نقية محلية وعالمية (أرامكو، مصرف الراجحي، STC، مايكروسوفت...).
  - صكوك سيادية إسلامية (صكوك حكومة المملكة 2030، صكوك البنك الإسلامي للتنمية الخضراء).
  - صناديق مؤشرات متوافقة (SPUS, HLAL).
  - سبائك ذهب مادي مخصص ومودع في خزائن معتمدة (AAOIFI Standard 57).
- **حاسبة الزكاة الذكية (Zakat & Hawl Tracker)**:
  - احتساب زكاة المال السنوية بنسبة 2.5% وفق معيار الأيوفي (35).
  - عداد تنازلي لموعد اكتمال حول المال ومؤشر بلوغ النصاب الشرعي.
- **تطهير الأرباح (Dividend Purification)**:
  - احتساب نسب الإيرادات العرضية للشركات المساهمة وإخراجها بنقرة واحدة للجمعيات الخيرية (منصة إحسان، جود الإسكان).
  - إصدار شهادات تطهير موثقة.

### 3. 🤖 المستشار والطيار الآلي الذكي (AI Autopilot & Advisor)
- **وضع الطيار الآلي (Autopilot Mode)**: إدارة ذاتية للسيولة وتنفيذ فوري لعمليات إعادة التوازن عند انحراف الأوزان.
- **3 محافظ استثمارية شرعية**:
  1. **المحفظة المتحفظة**: 65% صكوك، 15% ذهب، 15% أسهم، 5% صناديق.
  2. **المحفظة المتوازنة**: 40% أسهم، 30% صكوك، 20% صناديق، 10% ذهب.
  3. **محفظة النمو الجريء**: 65% أسهم، 20% صناديق، 10% صكوك، 5% ذهب.
- **استبيان الملاءمة وتحمل المخاطر**: 5 أسئلة ديناميكية لتحديد المحفظة الأنسب تلقائياً.
- **سجل قرارات الذكاء الاصطناعي المباشر**: تفسيرات حية فقهية ومالية لكل قرار استثماري.
- **محادثة المستشار الآلي ("اسأل نماء")**: مساعد ذكي للإجابة على الفتاوى وأحكام الاستثمار.

### 4. 📈 محاكي الأهداف المالية والعائد المركب
- خطط ادخار واستثمار لأهداف كبرى: **أداء فريضة الحج، منزل الأحلام، التقاعد المبكر الحر، وصندوق تعليم الأبناء**.
- محاكي رسومي تفاعلي لمقارنة النمو المركب الحلال مقابل الادخار النقدي التقليدي.

### 5. 📱 تطبيق ويب تقدمي (Progressive Web App - PWA)
- دعم كامل للتثبيت على هواتف iOS و Android.
- ملف `manifest.json` بالعربية و Service Worker للتصفح السريع والعمل دون اتصال.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS (RTL) + Custom Glassmorphism & Emerald Design System
- **Icons**: Lucide React
- **Charts**: Recharts (Responsive AreaChart & PieChart)
- **Effects**: Canvas-Confetti
- **PWA**: Service Worker & Web App Manifest

## 💻 التثبيت والتشغيل المحلي (Getting Started)

```bash
# 1. استنساخ المستودع
git clone https://github.com/Omar-i3/es.git
cd es

# 2. تثبيت الحزم
npm install

# 3. تشغيل السيرفر المحلي
npm run dev

# 4. بناء نسخة الإنتاج
npm run build
```
